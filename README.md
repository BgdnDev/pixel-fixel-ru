# Pixel Fixel - Russian Localization Project

Проект технической локализации и LQA-тестирования игры **Pixel Fixel** на русский язык.

## Цели проекта
* Полный перевод интерфейса, названий тем, палитр и игровых элементов.
* Создание терминологического глоссария для обеспечения единого стиля.
* Проверка верстки и длины строк (LQA) в среде NW.js/Construct.

## Структура репозитория
* `glossary.md` - глоссарий терминов и названий.
* `loc/` - файлы с локализованными строками JSON.
