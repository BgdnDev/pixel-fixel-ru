# Глоссарий локализации Pixel Fixel

Глоссарий для сохранения единства терминологии при переводе игры.

| Оригинал (EN) | Перевод (RU) | Контекст |
| --- | --- | --- |
| Deuteranopia | Дейтеранопия | Режим доступности (дефект зелёных рецепторов) |
| Protanopia | Протанопия | Режим доступности (дефект красных рецепторов) |
| Tritanopia | Тританопия | Режим доступности (дефект синих рецепторов) |
| Funkstille | Тишина | Немецкий термин (радиомолчание) |
| Vinny The Pin| Винни-Пин | Имя собственное |
